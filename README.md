# NLP-Topic-Modeling

A comprehensive Natural Language Processing (NLP) pipeline designed to extract latent thematic structures and topics from unstructured text corpora. This project leverages statistical and machine learning methodologies to clean text, evaluate topic coherence, and visualize discovered textual themes.
Objectif : comparer 3 modèles de topic modeling
---

## 🚀 Features

* **Advanced Text Preprocessing:** Custom pipeline 
* **Vectorization Techniques:** Support for Bag-of-Words (BoW), TF-IDF matrix generation, and dense document embeddings.
* **Topic Extraction Models:** 
    * Latent Dirichlet Allocation (LDA)
    * DistilBert
    * Word2vec
